A single sentence of horror for the "One Line, One Chill" competition: a voicemail from a dead grandmother that knows an address it shouldn't. The entry is 110 characters long, well under the competition's 200-character limit, and the chill comes from a single impossible detail — the caller knows where the narrator lives now, not where she used to live.

## Run it

```sh
python3 main.py
```

It prints the entry and writes it to `/output/entry.txt`.
